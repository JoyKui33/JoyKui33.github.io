# joykui33.github.io

Personal portfolio and technical writing for Joy Wangui: systems administration and cloud infrastructure (AWS, GCP).

Built with plain HTML/CSS and Jekyll, served by GitHub Pages.

- `index.html`: home page
- `_posts/`: articles in Markdown (`YYYY-MM-DD-title.md`)
- `_layouts/`: page and article templates
- `assets/`: shared CSS and JS

Local preview: `bundle exec jekyll serve` or push to `main` and GitHub Pages rebuilds.
