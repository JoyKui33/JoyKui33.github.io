Preparing a Cloud Run platform for launch

Hardened a three-service platform before go-live: warm instances, regional HA database, a connection budget sized to the database tier, long-running AI requests moved onto a queue-backed worker, and a release pipeline that rehearses migrations and rolls back automatically.

02

Cutting latency-alert noise

Cloud Monitoring · alerting · SLOs

Latency alerts were firing per revision and status code, so a few slow but expected requests paged on their own. Rebuilt the policy around service-wide p95 and tested it against seven days of production metrics: seven false incidents removed.

IN PROGRESS
03

Tracing a failed CodeDeploy release

AWS · CodeDeploy · PM2 · RDS

A production release failed validation because the API never opened its port. Traced it from the deployment check to process logs to a malformed database host in the environment config, then changed the deploy hooks so the same class of failure is caught early.
